# Movie Streaming Website

## Project Overview

Build a modern movie and TV streaming website.

The platform will use an existing external streaming API for obtaining
streaming sources and playback information.

The streaming API already exists and must be integrated rather than rebuilt.

## Primary Goals

- Fast movie discovery
- Clean modern UI
- Reliable streaming playback
- Responsive desktop and mobile experience
- Search and filtering
- Movie and TV show detail pages
- Watch history
- Continue watching
- User profiles
- Watchlist

## Core Principles

- Performance first
- Mobile responsive
- Component-based architecture
- Secure API integration
- Minimal UI clutter
- Reliable error handling
- No unnecessary dependencies

## Important Constraint

The existing streaming API is the source of streaming data.

Do not create or replace the streaming backend unless explicitly instructed.
