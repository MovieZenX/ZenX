# UI / UX

## Design Direction

Modern cinematic streaming interface.

## Requirements

- Dark theme
- Large cinematic imagery
- Clear typography
- Minimal unnecessary controls
- Smooth transitions
- Responsive layout

## Main Pages

### Home
Hero + content rows

### Search
Search bar + filters + results

### Details
Backdrop + metadata + actions

### Watch
Large video player + episode/source controls

### Library
Watchlist + continue watching + history

### Profile
Account + preferences

## Mobile

Mobile must not simply be a scaled desktop layout.

Navigation, cards, player controls and spacing must be optimized for touch.
